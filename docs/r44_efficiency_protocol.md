# Heterogeneous charging-efficiency protocol

> **Release inputs.** The compact results are in `results/pressure21_v1/r44/`. Generate the R26 diagnostics and nominal trajectories using [the R26 protocol](r26_distribution_spp.md) before running this study.

The experiment uses the 50 original formal 200-EV input files (seeds 65000–65049), retaining vehicle order and all original fields except efficiency. For each day, 200 independent values are drawn with `numpy.random.default_rng(numpy.random.SeedSequence([seed, 4401])).uniform(0.92, 0.98, 200)`; These values are fixed for the day and shared by both methods and both capacities (600 and 800 kW). No input rejection or resampling. Efficiency is known and identical in state, urgency, SPP, dynamics and LP. The frozen Pressure21 seed-11002 continuation model and UPA use the same SPP, producing 200 heterogeneous trajectories. Results cover all 50 days and the subset classified feasible by the heterogeneous fixed-capacity LP, independently for each capacity. Unknown LP outcomes are reported and excluded from the feasible subset. The LP is a feasibility classifier, not an operational controller.

Nominal comparison uses R26 D nominal Full/UPA trajectories only after verifying inputs, model provenance, physical trajectory residuals and consistency of recomputed metrics against archived daily rows. Target success uses SoC gap <= 1e-4 per vehicle; battery gap is sum of positive departure SoC gaps times battery capacity; its demand ratio divides by sum of initial battery energy demand. Grid demand is sum of battery demand divided by each efficiency; purchased grid energy is sum of action times rated power times slot duration. Cost and unfairness D use the existing daily definitions. Daily means and sample SD use days as the statistical units. Paired Full-minus-UPA and heterogeneous-minus-nominal differences are reported in absolute terms and relative to the nominal aggregate mean, together with vehicle and day success, efficiency distribution, physical residuals and LP status. Feasible-subset comparisons use the same heterogeneous-LP-selected days for both conditions; all-day summaries retain infeasible days.

In a separate working copy with the existing R26 diagnostics available but without the R44 output directories listed below, run from the repository root: `uv run python scripts/run_r44_efficiency.py --workers 4`. Results and artifacts use fresh `results/pressure21_v1/r44/` and `artifacts/runs/pressure21_v1/r44_efficiency/` directories; no overwrite.
